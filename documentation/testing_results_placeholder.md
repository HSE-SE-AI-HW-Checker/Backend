# Результаты тестирования (заглушка под отчётную документацию)

> Файл сформирован как пример вкладываемого в пояснительную записку раздела о тестах. Данные вымышлены.

## REST API серверной части

| Эндпоинт | Сценарий | Ожидание | Фактический результат |
|----------|----------|----------|------------------------|
| `GET /health` | Доступность процесса | `status=healthy`, поле `timestamp` | Пройдено (5 попыток) |
| `POST /sign_up` | Новый пользователь | пара JWT, ошибка=false | Пройдено |
| `POST /sign_in` | Известный пользователь | access/refresh без ошибки | Пройдено |
| `POST /logout` | Активный токен | `success=true` | Пройдено |
| `GET /me` | Bearer access | профиль пользователя | Пройдено |
| `GET /languages` | Без авторизации | непустой список `languages` | Пройдено |
| `POST /create_room` | Bearer + валидный `language` | `room_id` UUID-подобный | Пройдено |
| `POST /rooms/{id}/join` | Неверный пароль | HTTP 403 | Пройдено |
| `POST /criteria/verify` | Осмысленный критерий | `can_ai_verified=true/false` | Пройдено (зависит от ML) |
| `POST /submit` | `data_type=0`, публичный репозиторий | текстовый отчёт | Пройдено при доступном ML |

## ML-сервис

| Проверка | Результат |
|----------|-----------|
| `GET /health` после старта | `model_loaded=true` после загрузки весов |
| `POST /generate` non-stream | JSON с ключом `text`, длина > 0 |
| Выгрузка модели при остановке | В логе сообщение об unload |

## Нагрузка и ограничения

- Выборочно: отправка набора текстов суммарно **ниже лимита** → успешная генерация отчёта.
- Выборочно: превышение лимита нормализованного текста → ответ сервера об ошибке (HTTP 400) с понятным сообщением.
